# TopTiroir 브랜드·컨셉 가이드

확정일: 2026-11-23 · 대상: macOS 노치·메뉴막대 활용 앱 (개인용)

## 1. 이름
| 항목 | 내용 |
|---|---|
| 앱 이름 | **TopTiroir** |
| 읽는 법 | 탑 티루아르 |
| 어원 | Top(영어, 맨 위) + tiroir(프랑스어 '티루아르', 서랍) |
| 뜻 | 화면 맨 위(노치·메뉴막대)에 달린 서랍. 영어 관용구 top drawer(최고급)와 겹치는 이중 뜻 |
| 코드·폴더 이름 | `toptiroir` (번들 ID 예: `com.<내이름>.toptiroir`) |
| 표기 규칙 | T와 두 번째 T만 대문자: TopTiroir (Toptiroir, Top Tiroir ✕) |
| 주의 | 말로 전하면 "탑 티루아르"를 영어로 받아 적기 어려우니 철자를 함께 알려 주기. 상표·앱스토어 겹침은 **직접 확인 필요** |

## 2. 앱 컨셉 (기획서 요약)
- **문제**: 맥북 노치가 눈에 띄고, 노치 때문에 메뉴막대 아이콘 자리가 부족함.
- **필수 기능**: 노치 좌우를 검게 칠해 노치 숨기기(해상도 지원 확대), 로그인 시 자동 실행.
- **필요 기능**: 노치를 누르면 메모·할 일 창이 서랍처럼 내려옴 / 노치 아래에 메뉴막대 한 줄 추가(2줄), 아이콘 표시 위치 설정.
- **있으면 좋은 기능**: 앱·폴더·파일·URL 즐겨찾기와 폴더 묶음(북마크 폴더처럼).
- **제외**: 메뉴막대 영역 밖 화면을 쓰는 기능.
- 참고: macOS는 진짜 메뉴막대를 옮기는 기능을 앱에 열어 주지 않아요. 2줄 메뉴막대는 앱이 노치 아래에 막대를 직접 띄우는 방식이 될 가능성이 크고, 가장 어려운 기능이에요.

### 하위 기능 이름 제안 (미확정, 서랍 비유로 통일)
| 기능 | 제안 이름 | 뜻 |
|---|---|---|
| 노치 숨김 | Blackout (블랙아웃) | 노치 주변을 검게 |
| 노치 메모·할 일 창 | Note Drawer / 쪽지 서랍 | 서랍 속 쪽지 |
| 2줄 메뉴막대 | Second Shelf / 둘째 칸 | 서랍장의 둘째 칸 |
| 즐겨찾기 묶음 | Compartments / 칸막이 | 서랍 안 칸막이 |

## 3. 앱 아이콘 — "열린 서랍"
- 검은 윗띠 = 노치를 숨긴 메뉴막대, 주황 서랍 앞판, **노치 모양 검은 손잡이**, 서랍 속 흰 쪽지(메모 기능).
- 64px 이상은 `app-icon.svg`, **32px 이하는 `app-icon-small.svg`**(쪽지 줄·안쪽 그림자를 빼고 서랍·손잡이를 키운 버전).
- macOS 모양(둥근 사각형, 1024 캔버스 안 824×824, 모서리 185)이 이미 들어 있어요.

## 4. 메뉴막대 아이콘 — "노치 실루엣"
- 가로선 가운데가 아래로 볼록한 모양. **템플릿 이미지**(검정+투명만 쓰는 그림. 다크 모드에서 macOS가 자동으로 흰색으로 바꿔 줌).
- 크기: 18×18pt. 파일 `MenuBarIconTemplate.png`(18px), `@2x`(36px), `@3x`(54px), 원본 SVG.
- Xcode에서 쓰는 법: Assets에 이미지 세트를 만들고 파일을 넣은 뒤, 오른쪽 속성에서 **Render As → Template Image**. 코드로는 `image.isTemplate = true`.
- 파일 이름 끝이 `Template`이면 macOS가 템플릿 이미지로 인식해요.

## 5. 색 코드
| 용도 | 색 |
|---|---|
| 노치·윗띠·손잡이 검정 | `#0B0C10` |
| 서랍 주황 (위→아래 그라데이션) | `#F7B23B` → `#E08E12` (단색일 때 `#F5A623`) |
| 배경 남색 (위→아래) | `#232A3D` → `#34405F` |
| 서랍 안쪽 | `#11141C` |
| 쪽지 / 쪽지 줄 | `#FFFFFF` / `#B9C2D6` |

## 6. 파일 목록
```
TopTiroir-handoff/
├─ TopTiroir-브랜드-가이드.md   ← 이 문서
├─ preview.png                  ← 한눈에 보는 미리보기
├─ app-icon/
│  ├─ app-icon.svg              ← 원본(64px 이상)
│  ├─ app-icon-small.svg        ← 원본(32px 이하)
│  ├─ app-icon-16~1024.png      ← 크기별 PNG
│  ├─ AppIcon.icns              ← macOS 앱 아이콘
│  └─ AppIcon.iconset/          ← Xcode·iconutil용 크기별 세트
└─ menubar/
   ├─ MenuBarIconTemplate.svg
   └─ MenuBarIconTemplate.png / @2x / @3x
```
- `.icns`를 맥에서 다시 만들고 싶으면 (Mac 터미널, 압축 푼 app-icon 폴더에서):
  ```
  iconutil -c icns AppIcon.iconset
  ```
- 아직 없는 것: 로고(이름 글자 디자인). 필요하면 디지털 작명소에서 따로 진행.
